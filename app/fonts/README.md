# Fonts

`general-sans-*.woff2` is **General Sans** from Fontshare (Indian Type Foundry), downloaded from
`cdn.fontshare.com` and served from this site, so pages do not wait for another website and no
visitor details are sent to it. Fontshare fonts are free for personal and commercial use under the
ITF Free Font License (https://www.fontshare.com/licenses/itf-ffl): self-hosting is allowed; keep this
note with the files. Loaded in `app/layout.tsx` with `next/font/local`.
